# Album Art

Customize the behavior, appearance, and animations of the album cover displayed within the lyrics window.

## Album Style
- **Album Radius**: Adjust the corner rounding of the album cover image (from 0% for a sharp square, up to 100% for a perfect circle).
- **Album Shadow Amount**: Increase or decrease the size and intensity of the drop shadow rendered behind the album cover (0-64).

## Album Effect
- **Image Switch Type**: Choose the transition animation when a song changes and a new album cover loads:
  - **Crossfade**: The old cover smoothly blends into the new cover.
  - **Slide**: The new cover slides in over the old one.
- **Fade Out Mask**: Applies a directional transparency gradient to the album cover. You can precisely configure the Start Point (X,Y) and End Point (X,Y) coordinates to control the direction and intensity of the fade.
- **Parallax Tilt**: Enables a 3D interactive effect where the album cover dynamically tilts in response to your mouse cursor hovering over it.

## Song Info Effect
- **Song Info Auto Scroll**: Enables a scrolling marquee animation for the song title and artist text. This ensures that very long track names that exceed the available width are completely readable.
