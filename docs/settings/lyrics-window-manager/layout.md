# Layout

The **Layout** tab allows you to select, manage, and customize the layout profiles for your lyrics window. A layout profile dictates precisely where the album art, lyrics, and controls are placed within the window.

## Layout Profiles

Layout profiles are divided into two categories:

- **System Profiles**: Built-in default layouts provided by BetterLyrics. These cannot be deleted or directly modified.
- **Custom Profiles**: Layouts you create yourself or import from others. You can freely edit, share, or delete them.

### Managing Profiles

On any profile card, you can:
1. **Apply**: Click the card to apply the layout to the current lyrics window. A real-time preview is displayed on the card.
2. **Edit (Gear Icon)**: Opens the **Visual Layout Editor** ([see Visual Layout Editor](/docs/settings/lyrics-window-manager/layout-editor)) to customize the layout. *(Note: System profiles cannot be edited directly; you must duplicate them first).*
3. **More Options (...)**:
   - **Create from Current**: Duplicates the profile so you can edit it.
   - **Share**: Exports the layout file to share with others.
   - **Delete**: Removes a custom profile.
   - **View Applied Lyrics Window**: Highlights which window(s) are currently using this layout.

At the bottom of the page, you can:
- Browse the **[Layouts Store](/docs/add-ons/modes-store)** to download community-made layouts.
- **Create from Templates** to start a new custom layout from scratch or a base template.
- **Import** a .json layout file.
