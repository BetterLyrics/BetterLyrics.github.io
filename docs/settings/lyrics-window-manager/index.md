# [Lyrics Window Manager](betterlyrics://settings/LyricsWindowMgr)

The **Lyrics Window Manager** allows you to manage and customize individual lyrics windows. BetterLyrics supports displaying multiple lyrics windows simultaneously, and each window can have its own completely independent configuration.

## Managing Windows

In the main view, you will see a list of your current lyrics windows (e.g., Standard Mode, Desktop Mode, etc.).

- **Multi-Window Mode**: Enable Allow Multiple Now Playing Windows to display more than one lyrics window at the same time.
- **Create New Window**: Click the **Create from Templates** button to add a new window based on predefined templates (Standard, Desktop, Docked, Fullscreen, Narrow, Taskbar, Wallpaper).
- **Import/Share**: You can export your window configuration to share with others, or import community-made window styles from the [Modes Store](/docs/add-ons/modes-store).

## Window Configuration Panel

Click the **Gear icon** on any window card to open the **Configuration Panel**. This panel contains 6 tabs for deep customization of that specific window:

1. **[Window (General)](/docs/settings/lyrics-window-manager/window)**: Configure basic window behaviors like Topmost, Click-through, and monitor placement.
2. **[Layout](/docs/settings/lyrics-window-manager/layout)**: Select or edit the layout profile for this window using the Visual Layout Editor.
3. **[Album Art](/docs/settings/lyrics-window-manager/album-art)**: Customize the size, shape, and visibility of the album cover within the window.
4. **[Lyrics Style](/docs/settings/lyrics-window-manager/lyrics-style)**: Fine-tune typography, font sizes, alignment, and spacing.
5. **[Lyrics Effect](/docs/settings/lyrics-window-manager/lyrics-effect)**: Configure advanced animations, word-by-word highlights, and 3D effects.
6. **[Lyrics Background](/docs/settings/lyrics-window-manager/lyrics-background)**: Set up base backgrounds (pure color, blurred album art, fluid overlay), environmental effects (fog, snow, rain), and audio spectrum visualization.
