# General & Behaviors

## Appearance
This section contains settings for the application's base interface language.

- **Language**: Change the display language of the application. You will need to restart the app for the changes to take effect.
  - **Restart to Apply Changes**: Provides a one-click restart button.
  - **Help Us Translate**: Opens the Crowdin platform, inviting you to contribute to BetterLyrics' multi-language localization.

## Startup Behaviors
Controls the default actions when the application starts with Windows.

- **Auto Start**: When enabled, BetterLyrics will silently launch at boot and stay in the system tray, ready to respond to music playback.
- **Auto Open Default Lyrics Window on Startup**: If enabled, the main lyrics floating window (e.g., Desktop mode or Standard mode) will automatically pop up on your screen right after launch.

## Exit Behaviors

- **Exit Application on Lyrics Window Close**: By default, closing the main lyrics window only hides it to the system tray. Checking this option will completely terminate the application when the lyrics window is closed.

## Global Hotkeys
BetterLyrics supports global hotkey registration (meaning the software will respond even when running in the background), allowing you to control music and lyrics anytime, anywhere.

You can bind custom key combinations for the following actions:
- **Show/Hide Lyrics Window**: A quick toggle for the floating window's visibility, perfect for seamlessly switching between work and entertainment.
- **Switch Lyrics Window Status**: Rapidly cycle through different window modes (Standard, Fullscreen, Docked, Desktop, etc.).
- **Media Controls**:
  - Play / Pause
  - Previous Track
  - Next Track
