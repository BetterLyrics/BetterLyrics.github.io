# 插件商店

## 如何安装
1. 点击插件卡片进入其 GitHub Release 页面。
2. 从最新发布的 Assets 中下载以 `.blp` 结尾的插件安装包。
3. 将下载的 `.blp` 文件直接拖拽到 BetterLyrics 设置窗口中，或直接双击运行以进行安装。*（或者进入 **设置** -> **插件管理** 页面手动导入并启用该插件）。*
