# Music Center for PC

> An application for organizing and transferring music on audio devices manufactured by Sony[^1]

## Setup Guide

**Configuration required**.

### Basic Setup

To use Music Center for PC with BetterLyrics, you need to install the following plugin:

[SonyMusicCenter-SMTC-Bridge](https://github.com/jayfunc/SonyMusicCenter-SMTC-Bridge)

Follow the installation instructions provided in the plugin's repository to set it up. Once installed and configured, BetterLyrics will be able to retrieve playback information properly.

[^1]: [Music Center for PC](https://www.sony.com/electronics/support/articles/MC4PC020001)
