# 实时状态与数据

此页面提供当前播放歌曲的实时诊断信息、歌词匹配的详细来源，以及本地歌词导出的配置项。

## 播放器与歌曲状态
- **播放源**: 实时显示当前提供音频数据的音乐播放器 ID 和名称。
- **歌曲状态**: 实时读取当前歌曲的标题、艺术家、专辑以及总时长。

## 搜索结果诊断
精准展示当前歌曲的歌词是如何被匹配出来的：
- **标题 / 艺术家 / 专辑**: 用于此次搜索的具体元数据。
- **语言代码**: 自动检测出的歌词语种。
- **歌词提供者**: 提供主歌词数据的服务商（如网易云、LrcLib）。
- **音译与翻译提供者**: 提供注音和翻译数据的服务商。
- **匹配度 (Match Percentage)**: 搜索算法对此次匹配结果的置信度百分比。

## 歌词保存 (导出) 配置
点击诊断面板底部的设置图标，可展开本地 .lrc 歌词文件的导出设置：
- **格式选项**: 可自由勾选保存的文件中是否包含逐字信息 (Syllables)、翻译 (Translation)、音译/注音 (Transliteration)，以及是否将多行内容合并为单行 (In One Line)。
- **文件名规则**: 自定义导出的 .lrc 文件的命名正则表达式。
- **保存目录**: 选择歌词文件存放到本地电脑的具体路径。
