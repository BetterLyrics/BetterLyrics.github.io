# 播放源配置

配置 BetterLyrics 连接和获取各类音乐播放器数据的核心逻辑。

## 播放源提供者管理
- **媒体源优先级列表**: 一个支持拖拽排序的已安装播放器列表（例如 Spotify、Apple Music、网易云音乐等）。通过拖拽调整顺序，决定 BetterLyrics 优先尝试连接哪个播放源。
- **监听新播放源**: 开启后，如果后台启动了一个新的音乐播放器，软件会自动无缝切换过去监听新播放器。

## 独立播放源配置

> [!NOTE]
> **本地歌词搜索源：** 如果您调高了本地歌词搜索提供者的优先级，请务必记得先前往 [媒体库](../media-library.md) 添加包含本地歌词的文件夹路径。

点击列表中任意提供者右侧的齿轮图标，可以对其进行专项配置：
- **启用/禁用**: 决定是否允许 BetterLyrics 连接到该播放器。
- **内存读取器 (Memory Reader)**: 对于支持的播放器，启用内存读取可绕过系统标准 API 直接获取最精准的播放进度。你也可以导入自定义的内存特征码配置。
- **Last.fm 记录**: 专门为该播放源开启或关闭 Last.fm 听歌记录同步。
- **Discord 状态展示**: 专门为该播放源开启或关闭 Discord Rich Presence 状态显示。
- **LX Music 服务器等特定设置**: 部分特殊播放器需要手动输入 API 地址（如 LX Music 的 WebSocket 服务器）。
- **时间轴同步与偏移**: 设置同步的阈值，或手动调整歌词时间轴偏移量（例如 +500ms 延迟）以修正音频不同步的问题。支持切歌时自动重置偏移量。
- **专辑封面搜索源**: 拖拽配置专辑封面补全的搜索源优先级，并设定期望下载的封面分辨率。
- **歌词搜索源**: 拖拽排序歌词源（网易云、QQ音乐、LrcLib 等）。可选择 **按顺序获取 (Sequential)** 或 **最佳匹配 (Best Match)** 策略。可全局或为每个源单独设定匹配度阈值（例如 60%）。
