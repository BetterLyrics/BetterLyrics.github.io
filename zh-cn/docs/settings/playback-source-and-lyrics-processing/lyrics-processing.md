# 歌词处理

配置原始歌词文本如何被解析、翻译以及转换。

## 歌词翻译
- **目标语言**: 选择你希望将外语歌词翻译成的语言。
- **LibreTranslate**: 启用自建或公开的 LibreTranslate 服务器进行机器翻译，以摆脱内置 API 的请求限制。可输入服务器 URL 并测试连通性。

## 罗马音与注音
开启后，将在原文歌词上方显示拼音或罗马音，方便跟唱：
- **拼音 (Pinyin)**: 适用于中文普通话。
- **粤拼 (Jyutping)**: 适用于粤语。
- **罗马音 (Romaji)**: 适用于日语。
- **罗马字 (Romaja)**: 适用于韩语。

## 文本调整
- **简繁转换 (Chinese Conversion)**: 自动将中文歌词强制转换为简体 (T2S)、繁体 (S2T)，或者保持原样。
- **脏话过滤 (Profanity Filter)**: 自动对歌词文本中的敏感/不雅词汇进行打码过滤。

## 异常回退行为
- **未找到歌词时的处理**: 当全网搜索失败时，选择是显示“未找到歌词”的提示，还是直接隐藏整个歌词区域。你可以自定义未找到时的具体提示文本。
- **自动重试次数**: 设定在放弃之前，软件应该自动尝试重新拉取歌词的次数（1-10次）。
