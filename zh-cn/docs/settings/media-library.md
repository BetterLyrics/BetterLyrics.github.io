# [媒体库](betterlyrics://settings/MediaLib)

在此管理你的本地音乐文件夹以及媒体库的扫描和索引行为。

## 媒体源
你可以添加多个目录以供 BetterLyrics 扫描本地音频文件。点击右下角的 **添加文件夹** 按钮来添加媒体源。支持以下类型的源：
- **本地文件夹 (Local Folder)**: 标准的本地硬盘和目录。
- **SMB**: Windows 局域网共享文件夹。
- **FTP**: 标准 FTP 服务器。
- **WebDAV**: WebDAV 网络驱动器。

## 文件夹配置
点击列表中的任意文件夹卡片即可展开其高级配置项：

- **名称**: 为该媒体源自定义一个易于辨识的显示名称。
- **本地音乐文件名匹配规则**: 当音乐文件缺失 ID3 标签时，设定从文件名中提取歌曲元数据（如标题、艺术家）的正则表达式规则。
- **本地歌词文件名匹配规则**: 设定如何匹配同目录下的外挂 .lrc 或 .txt 歌词文件。
- **上次同步时间**: 显示该文件夹最后一次完成扫描的时间。
  - **立即同步**: 点击按钮立即执行一次差异扫描。
  - **高级选项 -> 强制完全同步**: 彻底清空并重新构建该文件夹的全部索引数据。
- **自动同步间隔**: 设置后台自动扫描该文件夹的频率（禁用、每15分钟、每1小时、每6小时、或每天）。
- **实时扫描监控**: （仅限本地文件夹）动态监听文件夹内的文件变化，并在文件增删时瞬间更新媒体库，无需等待同步间隔。
- **扫描子目录**: 切换是否递归扫描此路径下的所有子文件夹。
- **移除路径**: 将此文件夹从媒体库中断开连接，并清除其建立的索引数据。

在页面底部，提供了一个快速打开 **音乐库 (Music Gallery)** 窗口的快捷入口。
> [!TIP]
> **本地歌词：** 如果您希望软件能够读取本地的 `.lrc`、`.eslrc` 或 `.ttml` 歌词文件（以及本地音乐文件），也请务必在此处将包含它们的文件夹添加到媒体库中。
