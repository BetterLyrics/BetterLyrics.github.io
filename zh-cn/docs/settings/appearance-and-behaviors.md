# 通用设置与行为

## 应用外观 (Appearance)
在此部分可以设置应用程序的基础界面语言。

- **语言 (Language)**：更改应用程序的界面语言。更改后需要重启应用以生效。
  - **重启应用以应用更改**：提供了一键重启功能。
  - **帮助我们翻译此应用程序**：跳转到 Crowdin，邀请你参与 BetterLyrics 的多语言本地化工作。

## 启动行为 (Startup Behaviors)
此部分控制应用程序随 Windows 系统启动时的默认动作。

- **自动启动 (Auto Start)**：开启后，BetterLyrics 将在开机时静默启动，常驻托盘以备随时响应音乐播放。
- **启动时自动打开默认歌词窗口**：若开启，程序启动后会自动在桌面上呼出歌词悬浮窗（如桌面模式或标准模式）。

## 窗口退出行为 (Exit Behaviors)

- **关闭歌词窗口时退出程序**：默认情况下，关闭主歌词窗口只会将其隐藏到系统托盘。如果勾选此项，关闭歌词窗口将直接彻底退出应用程序。

## 全局快捷键 (Global Hotkeys)
BetterLyrics 支持注册全局快捷键（即使软件在后台也能响应），让你随时随地掌控音乐与歌词。

你可以为以下操作绑定自定义的组合键：
- **歌词窗口显示/隐藏**：一键切换悬浮窗的可见状态，适合在工作和娱乐间快速切换。
- **歌词窗口状态切换**：在不同的窗口模式（标准、全屏、悬浮等）间快速循环切换。
- **媒体控制**：
  - 播放 / 暂停 (Play / Pause)
  - 上一曲 (Previous Track)
  - 下一曲 (Next Track)
## 正在播放通知 (Now Playing Notifications)

每当切换到新歌曲时，BetterLyrics 可以在屏幕上显示一个简短的通知。

- **启用通知**: 在歌曲切换时，显示包含专辑封面、歌曲名和歌手信息的弹窗通知。
- **通知位置 (Corner)**: 选择通知在屏幕上的显示位置（例如：左上角、右下角、顶部居中等）。
- **所有显示器 (All Monitors)**: 开启后，通知将在所有连接的显示器上弹出，而不仅仅是主显示器。
- **显示时长 (Duration)**: 调整通知在屏幕上的停留时间（2000毫秒 至 10000毫秒）。

## 系统托盘行为 (System Tray Behaviors)

你可以自定义 BetterLyrics 在 Windows 系统托盘中的图标行为。

- **彩色图标**: 在标准单色图标和彩色图标之间切换。
- **点击操作**: 为托盘图标的左键单击、双击和中键单击分配自定义操作。
  - 可选操作包括：无操作、切换歌词窗口、打开歌词搜索、打开媒体库、打开统计信息、切换歌词卡片或打开设置。
