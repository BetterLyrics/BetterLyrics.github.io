# 歌词样式

在此面板中，你可以对歌词的文本排版、字体、颜色以及透明度进行像素级的微调。

## 文本与排版

- **对齐方式**: 设定歌词块的水平对齐（左、中、右、两端对齐）与垂直对齐（上、中、下、两端对齐）。可以开启 **使用内部对齐规则** 来覆盖默认布局。
- **排版方向 (水平/垂直)**: 选择歌词是常规的 **水平横排** 还是传统的 **垂直竖排** 显示。
- **多层级歌词排序**: 通过拖拽列表，自由调整 **主歌词 (原词)**、**翻译歌词** 和 **音译歌词** 的上下堆叠顺序。
- **自动换行**: 当单句歌词过长超出窗口边缘时，自动折行显示，确保完整可见。
- **当前行垂直偏移**: 调节当前正在演唱的歌词行在屏幕上的垂直焦点位置（例如 50% 为绝对居中，30% 则偏向屏幕中上部）。
- **行间距调整**:
  - **全局行距因子**: 控制两行独立歌词之间的垂直间距。
  - **行内间距因子**: 控制同一行中，原词与其翻译、音译词之间的垂直距离。

## 字体设置

- **字体选择**: 可以分别独立为 **中日韩 (CJK) 字符** 以及 **西文字符** 选择不同的字体。
- **字体粗细**: 支持从极细 (Thin) 到特黑 (Extra Black) 等多种字重选择。
- **字体描边宽度**: 为歌词文字添加外边缘描边 (0-10px)，使其在复杂的背景或封面下依然清晰可读。
- **字号大小**: 可开启 **自动调整** 动态适应窗口，或关闭后分别为 原词、翻译词、音译词 单独设定固定的字号 (12-256)。

## 颜色与透明度

- **字体颜色**: BetterLyrics 提供了智能取色（适应自取色、适应灰度色）或自定义颜色功能。你可以分别为 5 种不同状态的文本设定颜色：
  - 已播放文字描边
  - 未播放文字描边
  - 非当前行（背景歌词）颜色
  - 当前行已播放文字前景色
  - 当前行未播放文字前景色
- **透明度 (Opacity)**: 精确微调各级歌词的透明度 (0-100%)：
  - 音译歌词透明度
  - 已播放原词透明度（默认 100%）
  - 未播放原词透明度（默认 30%，以凸显演唱焦点）
  - 翻译歌词透明度（默认 60%）

## 卡片样式
- **歌词卡片样式**: 为当前的歌词展示选择预设的卡片化视觉风格（若适用）。
