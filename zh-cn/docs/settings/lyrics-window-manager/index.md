# [歌词窗口管理](betterlyrics://settings/LyricsWindowMgr)

**歌词窗口管理**面板允许你管理和自定义各个独立的歌词窗口。BetterLyrics 支持同时显示多个歌词窗口，并且每个窗口都可以拥有完全独立的配置。

## 窗口管理列表

在主界面中，你将看到当前已有的歌词窗口列表（例如：标准模式、桌面模式等）。你可以通过拖拽来调整它们的顺序。

- **多窗口模式**: 勾选允许多个正在播放窗口同时存在后，你可以在屏幕上同时开启多个不同的歌词窗口。
- **新建窗口**: 点击 **从模板创建** 按钮，可以基于预设模板（如标准、桌面、停靠、全屏、状态栏、壁纸等）添加一个新的歌词窗口。
- **导入/分享**: 你可以将你的窗口配置导出分享给他人，也可以点击导入按钮，或前往 [模式商店](/zh-cn/docs/add-ons/modes-store) 获取社区制作的精美窗口样式。

## 窗口配置面板

点击任意窗口卡片上的 **齿轮图标 (设置)** 即可打开右侧的**配置面板**。该面板包含 6 个选项卡，用于对该窗口进行深度定制：

1. **[窗口 (Window)](/zh-cn/docs/settings/lyrics-window-manager/window)**: 配置基础窗口行为，例如置顶显示、鼠标穿透、以及绑定到特定显示器等。
2. **[布局 (Layout)](/zh-cn/docs/settings/lyrics-window-manager/layout)**: 为该窗口选择布局方案，或使用可视化布局编辑器深度定制界面元素的位置。
3. **[封面 (Album Art)](/zh-cn/docs/settings/lyrics-window-manager/album-art)**: 自定义窗口内专辑封面的大小、形状及显示状态。
4. **[歌词样式 (Lyrics Style)](/zh-cn/docs/settings/lyrics-window-manager/lyrics-style)**: 精确调节原词、翻译词、音译词的字体、字号、对齐方式与行距。
5. **[歌词动效 (Lyrics Effect)](/zh-cn/docs/settings/lyrics-window-manager/lyrics-effect)**: 配置逐字高亮、缩放浮动、3D 空间翻转等高级动效。
6. **[歌词背景渲染 (Background Overlay)](/zh-cn/docs/settings/lyrics-window-manager/lyrics-background)**: 设置基础背景（纯色、封面模糊、流体效果）、环境特效（雾、雪、雨）以及音频频谱动效。
