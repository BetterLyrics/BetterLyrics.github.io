# 布局 (Layout)

**布局**选项卡允许你为当前的歌词窗口选择、管理并自定义布局配置方案。布局方案决定了专辑封面、歌词文本以及控制栏等元素在窗口中的精确位置。

## 布局方案管理

布局方案被分为两个独立区域：

- **系统方案 (System Profiles)**: BetterLyrics 内置的默认布局方案。这些方案是只读的，不能被直接修改或删除。
- **自定义方案 (Custom Profiles)**: 你自己创建或从外部导入的布局方案。你可以自由编辑、分享或删除它们。

### 操作指南

在任意一个布局方案卡片上，你可以进行以下操作：
1. **应用**: 点击卡片即可将该布局应用到当前的歌词窗口。卡片上会实时显示该布局的微缩预览图。
2. **配置 (齿轮图标)**: 点击打开右侧的 **可视化布局编辑器**（[详见 可视化布局编辑器](/zh-cn/docs/settings/lyrics-window-manager/layout-editor)）以对布局进行深度定制。*(注意：系统内置方案无法直接编辑，你需要先点击复制创建它的副本)*。
3. **更多选项 (...)**:
   - **创建副本**: 复制当前方案，生成一个可编辑的自定义方案。
   - **分享**: 导出当前布局文件以便分享给他人。
   - **删除**: 移除该自定义方案。
   - **查看已应用的歌词窗口**: 提示当前有哪些正在运行的歌词窗口正在使用此布局。

在页面底部，你可以：
- 前往 **[模式商店 (Share Hub)](/zh-cn/docs/add-ons/modes-store)** 浏览并下载社区分享的精美布局。
- **从模板创建**: 基于预设模板新建一个完全空白或基础的自定义布局。
- **导入**: 导入本地的 .json 布局配置文件。
