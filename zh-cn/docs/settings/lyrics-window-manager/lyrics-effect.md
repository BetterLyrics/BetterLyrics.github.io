# 歌词动效

在此面板中配置歌词渲染引擎的高级视觉动画与 3D 特效。

## 高级歌词动效

- **逐字高亮模式**: 控制何时启用逐音节高亮（自动、从不、总是）。“自动”模式下仅当歌词文件包含精确音节时间戳（如增强版 LRC 或 TTML）时生效。
- **模糊效果**: 对未播放的背景歌词启用高斯模糊，使当前正在演唱的歌词更加突出。
- **淡出效果**: 在歌词列表的顶部和底部添加透明度渐变，使滚动的歌词平滑地隐没。
- **边缘羽化**: 柔化歌词渲染区域的边界。
- **远离视野 (Out of Sight)**: 当歌词滚动离开当前活动行较远时，在视觉上向后方淡出消失。
- **呼吸效果**: 当前播放的歌词行会进行轻微的大小缩放“呼吸”。可调节 **呼吸强度** (0-200%)。
- **发光效果 (Glow)**: 正在演唱的文字散发柔和光晕。
  - **作用范围**: 仅作用于长音节，或从行首作用至当前字。
  - **长音余韵触发时长**: 设定触发发光的长音阈值（如 700ms）。
  - **自动调整发光量**: 开启后由引擎计算发光强度，关闭后可手动调节 (0-16)。
- **缩放效果 (Scale)**: 放大当前演唱的歌词行或音节。
  - **长音触发时长**: 针对长音拖音时的动态缩放阈值。
  - **自动调整缩放量**: 开启后自动计算，关闭后可手动指定百分比 (100-200%)。
- **浮动动画 (Float)**: 歌词在滚动或停留时伴随轻微的上下浮动。
  - **自动调整浮动量**: 自动计算浮动幅度，关闭后可手动调节 (0-16)。
  - **动画周期**: 浮动一次的完整时长 (0-2000ms)。
- **扇形歌词**: 将平面的歌词行弯曲成 3D 扇面。可调节 **扇形角度** (-90° 至 90°)。

## 3D 空间 (3D Space)

将平面的歌词层投射到 3D 空间中，打造独特的透视歌词桌面。

- **开启 3D 歌词**: 启用 3D 渲染引擎。
- **自动 3D**: 软件会自动根据音乐的节奏和频谱，动态微调 3D 倾斜角度。
- **手动调整**（关闭自动时可用）：
  - **X, Y, Z 轴旋转**: 精确调节歌词平面的空间倾角 (-90° 至 90°)。
  - **3D 深度**: 调整透视纵深感 (100 至 1000)。

## 歌词滚动动画 (Scroll Easing)

高级选项，用于微调歌词滚动时的动画曲线和翻页时间。

- **缓动类型 (Easing Type)**: 选择数学曲线（线性, 柔和, 正弦, 二次, 三次, 指数, 弹跳等 12 种）。
- **缓动模式**: In, Out, InOut。
- **滚动时长**: 分别独立调节正常滚动、翻页到顶部、翻页到底部的动画耗时 (0-1000ms)。
- **滚动延迟**: 设置翻页到顶部或底部前的等待延迟时间 (0-2000ms)。
