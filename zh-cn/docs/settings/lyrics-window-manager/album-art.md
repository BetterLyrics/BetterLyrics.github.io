# 封面 (Album Art)

自定义歌词窗口中专辑封面的显示样式、转场动画及交互特效。

## 专辑封面样式
- **专辑圆角**: 调节封面图片的边缘圆角幅度（0% 为直角矩形，100% 为完美圆形）。
- **专辑阴影**: 增加或减少封面图片后方的投影范围和浓度 (0-64)，使封面更具立体感。

## 封面动效
- **图片切换效果**: 选择切歌并加载新封面时的转场动画：
  - **渐变 (Crossfade)**: 新旧封面平滑淡入淡出过渡。
  - **滑动 (Slide)**: 新封面从边缘滑入覆盖旧封面。
- **渐隐遮罩 (Fade Out)**: 为专辑封面添加方向性的透明渐变遮罩。你可以精确设置遮罩的起点 (X, Y) 与终点 (X, Y) 坐标，来控制渐变的方向和范围。
- **视差倾斜 (Parallax Tilt)**: 开启后，当鼠标在封面上方移动时，封面会产生跟随鼠标视角的 3D 倾斜交互效果。

## 歌曲信息动效
- **歌曲信息自动滚动 (Auto Scroll)**: 当歌曲名或歌手名字过长、超出可用显示宽度时，开启此项可让文本像跑马灯一样自动平滑滚动，确保你能看清完整的歌曲信息。
