## 如何安装

::: tip
如果有互相关联（即推荐）的布局/模式，为了获得最佳体验，请按照以下步骤进行完整安装：
1. 先在**模式商店**下载并导入对应的**模式**，此时**不要先打开该模式**。
2. 在歌词窗口管理中找到刚刚导入的模式，点击其右侧的“扳手”图标进入配置面板。
3. 切换到“**布局**”板块，导入您下载的本推荐**布局**。
4. 手动将该布局与对应的模式进行关联。
此时才算完整安装完成。
:::

1. 点击 **查看配置文件**，在新标签页中打开 `.json` 文件。
2. 在页面上右键并选择 **另存为...**（或使用 `Ctrl + S`），将其保存到本地电脑。
3. 打开 BetterLyrics 设置，进入 [**歌词窗口管理**](betterlyrics://settings/LyricsWindowMgr) -> 滚动到需要导入的模式，点击扳手图标打开配置面板，切换到“**布局**”，点按“**导入**”。
