## 如何安装

::: tip
如果有互相关联（即推荐）的布局/模式，为了获得最佳体验，请按照以下步骤进行完整安装：
1. 先下载并导入对应的**模式**，此时**不要先打开该模式**。
2. 点击该模式上的“扳手”图标进入配置面板。
3. 切换到“**布局**”板块，导入推荐的**布局**。
4. 手动进行关联。
此时才算完整安装完成。若不需要使用推荐布局，在安装完成模式后手动选取或新建其他布局关联即可。
:::

1. 点击 **查看配置文件**，在新标签页中打开 `.json` 文件。
2. 在页面上右键并选择 **另存为...**（或使用 `Ctrl + S`），将其保存到本地电脑。
3. 打开 BetterLyrics 设置，进入 [**歌词窗口管理**](betterlyrics://settings/LyricsWindowMgr) -> **导入**，然后选择下载的 `.json` 文件以应用该模式/状态。
