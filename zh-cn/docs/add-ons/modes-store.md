## 如何安装

::: tip
如果有建议使用的布局请先安装布局；若不想安装推荐布局那么请在安装完成模式后手动选取或新建布局并与该模式关联。
:::

1. 点击 **查看配置文件**，在新标签页中打开 `.json` 文件。
2. 在页面上右键并选择 **另存为...**（或使用 `Ctrl + S`），将其保存到本地电脑。
3. 打开 BetterLyrics 设置，进入 **歌词窗口管理** -> **导入**，然后选择下载的 `.json` 文件以应用该模式/状态。
